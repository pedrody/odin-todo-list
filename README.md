# odin-todo-list

This project is a to-do list app, built as part of [The Odin Project](https://www.theodinproject.com) JavaScript course, aiming to practice **ES6 modules, webpack, DOM manipulation, OOP, separation of concerns and localStorage**.

I chose a Kanban-style layout: each project has its own columns, and tasks live inside them.

The project is deployed via GitHub Pages, so you can easily [try it out here](https://pedrody.github.io/odin-todo-list).
